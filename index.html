clyops documentation

clyops registers command-line options in one line and resolves them consistently across Bash, JavaScript, TypeScript, Python, Rust, C, Go, Ruby and Java.

Choose a language guide for installation, a runnable example, editor support and its complete API reference. Start with shared behavior for validation, config, commands and completion.

Node tools and servers turn registered programs into JSON-driven tools, jobs, HTTP endpoints and MCP tools. The dispatcher and desktop runner provide a single command and generated forms for a directory of tools.

The specification defines shared behavior. Examples are compiled or executed by the docs build. References are generated from source signatures and comments; maintaining the docs describes the checks.

Guides are Markdown. API references come from the published source interfaces.
