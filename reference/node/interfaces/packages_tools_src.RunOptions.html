    OptionalkillGraceMs

    killGraceMs?: number

    How long a stopped tool (abort or timeout) has after SIGTERM to clean up and exit before its process tree gets SIGKILL. Default 200; Infinity waits as long as a timer can (about 24 days). On Windows the tree is stopped at once (taskkill /F), without a grace period.
