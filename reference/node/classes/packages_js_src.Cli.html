    complete

    • complete(name: string, fn: Completer, options?: CompleteOptions): this

      List the values of the value option or argument name of this level (spec section 9.2), for shell completion and --complete-values. The function gets a request (the words typed after the commands, a prefix, a limit and an offset) and returns strings. The library keeps the values starting with the prefix and pages them, unless paged is set: then the function applies the prefix, offset and limit itself, as a database query can. It doesn't validate anything. Registering a name again replaces it.

      Parameters

      • name: string
      • fn: Completer
      • options: CompleteOptions = {}

      Returns this
