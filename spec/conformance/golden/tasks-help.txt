Usage: tasks <command> [OPTIONS]

Commands demo for the clyops conformance suite.

Output fd 3 [progress]: Progress, one JSON object per line (application/x-ndjson)

Commands:
  db                            Database tasks
  send                          Send a message

Global:
  -v, --verbose                 Verbose output
  -h, --help                    Show this help message and exit

Run 'tasks <command> --help' for a command's options.
