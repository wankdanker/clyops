# clyops documentation

clyops registers command-line options in one line and resolves them consistently
across Bash, JavaScript, TypeScript, Python, Rust, C, Go, Ruby and Java.

Choose a [language guide](reference.md) for installation, a runnable example,
editor support and its complete API reference. Start with [shared behavior](guide.md)
for validation, config, commands and completion.

- [JavaScript / TypeScript](languages/javascript.md)
- [Python](languages/python.md)
- [Rust](languages/rust.md)
- [Go](languages/go.md)
- [Java](languages/java.md)
- [Ruby](languages/ruby.md)
- [C](languages/c.md)
- [Bash](languages/bash.md)

[Node tools and servers](node-tools.md) turn registered programs into JSON-driven
tools, jobs, HTTP endpoints and MCP tools. The [dispatcher and desktop runner](applications.md)
provide a single command and generated forms for a directory of tools.

The [specification](../spec/SPEC.md) defines shared behavior. Examples are compiled
or executed by the docs build. References are generated from source signatures
and comments; [maintaining the docs](maintaining.md) describes the checks.
