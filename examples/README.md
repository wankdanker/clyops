# Clone-and-run tools

These executable Bash and Python scripts use the libraries in this checkout.
No compilation, pip installation or PYTHONPATH setup is needed. Use Python 3.9+
and Bash 4.3+ (on macOS, install a current Bash and put it on PATH).

From the repository root:

```sh
./examples/scripts/plan.py --help
./examples/scripts/plan.py --env production --replicas 3 --tag demo
./examples/scripts/report.py --format table
./examples/scripts/json-format.py --input examples/data/service.json --sort
printf '{"z":2,"a":1}' | ./examples/scripts/json-format.py --sort
./examples/scripts/transcode.sh examples/data/tone.wav /tmp/clyops-demo.m4a
./examples/scripts/upload.sh examples/data/service.json --url https://example.com/upload
```

| Script | Demonstrates | Runtime dependencies |
| --- | --- | --- |
| `plan.py` | Choices, numeric ranges, repeatable tags, exclusive notification options, JSON output | Python standard library |
| `report.py` | CSV input, typed controls, filtering and enum output formats | Python standard library |
| `json-format.py` | Validated file paths, stdin, flags and JSON output | Python standard library |
| `media-info.sh` | File validation and a real FFprobe wrapper | Bash; FFmpeg for execution |
| `transcode.sh` | FFmpeg options, range/choice controls and explicit execution | Bash; FFmpeg with libx264/AAC for execution |
| `upload.sh` | HTTP PUT, a secret bearer token, timeout and declared network effects | Bash; curl for execution |

Transcode and upload print commands by default. Add `--execute` to perform the
operation. Transcode uses FFmpeg's `-n` to refuse overwriting an existing output.
Upload previews redact the token; `TOKEN` can supply it through the environment.
Only upload to an endpoint you intend to send the file to.
`media-info.sh examples/data/tone.wav` runs FFprobe when FFmpeg is installed.
The short generated tone, JSON document and CSV are sample data, not downloads.
Help, schemas and completion generation work without FFmpeg or curl.

Every script supports `--help-json-schema` and `--completion bash|zsh|fish`.
See [completion setup](../docs/completion.md).

To open this directory in the web runner, build the Node API once:

```sh
pnpm install --frozen-lockfile
pnpm build
node apps/api/dist/cli.js --root ./examples/scripts --port 8788
# Open http://127.0.0.1:8788/ui/
```

You will see the same choices, ranges, uploads, stdin and secret controls as the
command-line declarations. Tools run on the API's host. Their effect annotations
are shown before execution; wrappers still need `--execute` to act.

The same directory works with `clyops-mcp --root ./examples/scripts` and
`clyops-dispatch --root ./examples/scripts`. No scripts require a compiled binary;
the optional adapters themselves need their documented build/install steps.
For command names generated by an adapter, inspect its tools list or help.

The [homepage playground](https://clyops.io/#playground) runs the three Python
tools using the actual library and script sources in a browser workspace.
The [Linux lab](https://clyops.io/linux-lab.html) runs all six tools in real Linux
with Bash, Python, FFmpeg, curl and pipes, including an HTTP upload inside the
guest. See [the example guide](../docs/examples.md).

Run `python3 tools/test-examples.py` to check the scripts and wrapper previews.
